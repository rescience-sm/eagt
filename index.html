How to Publish the Participant Portal on GitHub?

To allow participants to enter their email or full name and download their certificate directly, click the button below to generate a locked public version of this page (with Admin settings protected by PIN and email addresses encrypted).

3-Step Deployment:

  1. In Admin Settings, upload your PDF template, adjust the text coordinates, and enter all participants (Full Name, Email).
  2. Click the green button below to download the ready-made index.html file containing your embedded PDF template and encrypted participant list.
  3. Upload that index.html file to your GitHub repository and enable GitHub Pages.
How does privacy protection (GDPR) work?

When exporting the public portal, email addresses and names are not stored in plain text in the source code. Instead, they are converted into a one-way cryptographic hash (SHA-256), and the participant's name and certificate ID are masked with a cipher key derived from the user's input. Nobody can extract the list of participants, and each attendee can unlock only their own certificate!
